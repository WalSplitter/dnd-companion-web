# `=this.file.name`
Lerne eine wilde Technik. Mit jedem Rang kommt eine weitere hinzu.

## Optionen
- **Todesstoß**: Nach einem kritischen Treffer verursachen ausgegebene Wutwürfel doppelten Schaden.
- **Kampfeslust**: Vorteil auf Initiative, im ersten Zug doppelte Bewegung.
- **Mitten hinein**: Springe auf einen Feind zu; neben zwei Feinden greifst du kostenlos an.
- **Mächtige Ausdauer**: Du überstehst 4 zusätzliche Wunden.
- **MEHR BLUT!**: Ein kritischer Treffer gegen dich gibt dir einen Wutwürfel.
- **Wirbelwind**: 2 Aktionen: Greife alle Ziele in Reichweite an.
- **Du bist der Nächste!**: Schüchtere einen Feind ein; gelingt es, flieht er.
